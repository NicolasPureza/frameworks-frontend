## 📑 Visão Geral do Conteúdo

### Contexto e Conceito de Front-end
* **Front-end:** É a camada de uma aplicação responsável pela interface com o usuário, pela experiência do usuário (`UX/UI`) e pela comunicação com o back-end/servidores.
* **Relevância:** Frameworks modernos garantem aplicações web rápidas, organizadas e fáceis de manter, tornando-se um requisito estratégico no mercado.
* **Vanilla JS:** JavaScript puro (sem dependências externas), servindo como base fundamental para o uso de qualquer framework.

### Arquitetura de Software e Ciclo de Desenvolvimento
* Definição de escopo, prototipação e design de interface (`UX/UI`).
* Uso de controle de versão (Git/GitHub) e integração de deploys automatizados (ex.: Vercel).
* Conceitos de componentização, gerenciamento de estado e consumo de APIs em frameworks como React, Vue e Angular.

* Desenvolver interfaces e aplicações web modernas utilizando Frameworks Front-end.

## 🛠️ Atividades da Aula

1. **Atividade 01 (Prática):**
   * Criar um projeto utilizando HTML, CSS e Vanilla JS.
   * Conectar a IDE com o GitHub e realizar o deploy da aplicação via Vercel.

2. **Atividade 02 (Em grupo de 3 a 5 integrantes):**
   * Criar o repositório principal no GitHub para o semestre e adicionar um resumo da Aula 01 em Markdown (`.md`).
   * Elaborar um relatório técnico em PDF (mínimo 5 páginas) sobre um Framework Front-end à escolha, detalhando características, vantagens e um exemplo prático.
